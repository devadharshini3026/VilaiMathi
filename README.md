# VilaiMathi – Fair Crop Pricing Platform

## About the Project
VilaiMathi is a farmer-focused web application designed to help farmers explore fair prices for their crops and find better selling opportunities. It aims to support direct connections between farmers and shop owners and reduce dependence on intermediaries.

## Features
- Farmer registration and login
- Add crop details, quantity, location, and expected price
- Crop price comparison page
- Tamil and English language options
- SQLite database integration

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Git and GitHub

## Project Goal
To support farmers in finding better selling opportunities and making informed decisions about crop pricing.

## Future Improvements
- Direct farmer-to-shop owner communication
- Updated market price information
- Improved crop search and filtering
